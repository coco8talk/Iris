@Component
public class RawQueryValidator {
    // LogQL 必须以 label selector 花括号开头
    private static final Pattern LOGQL_LABEL_SELECTOR =
            Pattern.compile("^\\s*\\{[^}]+\\}");

    // PromQL 必须包含至少一个 label matcher
    private static final Pattern PROMQL_LABEL_MATCHER =
            Pattern.compile("\\{[^}]*[a-zA-Z_][a-zA-Z0-9_]*\\s*(=~|!~|!=|=)\\s*\"[^\"]*\"[^}]*\\}");

    public void validateLogQL(String query) {
        if (!LOGQL_LABEL_SELECTOR.matcher(query).find()) {
            throw new RawQueryRejectedException("LogQL 查询必须以 label selector 开头，如 {app=\"xxx\"}");
        }
    }

    public void validatePromQL(String query) {
        if (!PROMQL_LABEL_MATCHER.matcher(query).find()) {
            throw new RawQueryRejectedException("PromQL 查询必须包含至少一个 label matcher，如 {service=\"xxx\"}");
        }
    }
}

# Iris Tool Gateway 工具契约

## 通用约定
- 鉴权：Authorization: Bearer <token>（AuthInterceptor 校验）
- 必需请求头：X-Incident-Id、X-Agent-Role（缺失 -> 400）
- 统一响应信封 ApiEnvelope：{ok, degraded, degradedReason, message, data,
  meta:{elapsedMs, truncated, toolCallsRemaining}}
- 限流：按 incident 维度，consume_tool_calls.lua 实现，当前上限 30 次/incident/24h，
  超限抛 ToolCallsExceededException
- 错误码：400 参数错误/未知 templateKey|service，401 鉴权失败，
  200+degraded=true 上游不可用，500 网关自身异常
